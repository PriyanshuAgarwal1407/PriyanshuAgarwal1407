### About

Computer Science undergraduate working across backend engineering with **Java & Spring Boot**, full-stack web development with **React and Next.js**, and data structures & algorithms. I care about clean, maintainable code, well-designed relational schemas, and REST APIs that behave predictably under real load.

- **Backend** — Layered service architecture, REST API design, and JWT/OAuth2 authentication with Java, Spring Boot, Node.js, and Express.
- **Frontend** — Responsive client applications in React and Next.js, styled with Tailwind CSS.
- **Databases** — Schema design and querying across PostgreSQL, MySQL, and MongoDB.
- **Algorithms** — Solving LeetCode problems in Java with a focus on time and space complexity; solutions collected in [LeetcodeQuestion](https://github.com/PriyanshuAgarwal1407/LeetcodeQuestion).
